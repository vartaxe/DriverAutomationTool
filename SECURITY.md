# Security Policy

## Supported Versions

This fork follows the upstream Driver Automation Tool 10.x release line. Fork-specific maintenance
changes are supported on the default branch only.

| Version | Supported          |
| ------- | ------------------ |
| 10.x.x  | :white_check_mark: |
| < 10.0  | :x:                |

## Reporting a Vulnerability

For vulnerabilities in the upstream Driver Automation Tool product, follow the
[upstream security policy](https://github.com/maurice-daly/DriverAutomationTool/security/policy)
or report them to `maurice.daly@outlook.com`.

For vulnerabilities introduced by this fork's maintenance changes, use
[private vulnerability reporting](https://github.com/vartaxe/DriverAutomationTool/security/advisories/new).
Do not disclose an unpatched vulnerability in a public issue or discussion.

No response or remediation SLA is provided, in line with the upstream EULA.
